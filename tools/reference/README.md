# Upstream reference tools

`codeinfo.py`, `recomp.py`, `r5900.py`, and `iop_recomp.py` are reference
recompiler components vendored into this repository so EE/IOP generation can
run without a separate checkout.

They originate from the Grandia 3 PC recompilation toolchain/runtime lineage
used by this project. Preserve upstream attribution and the MIT license text in
`Grandia3-PC-LICENSE` when redistributing this repository or derived binaries.
